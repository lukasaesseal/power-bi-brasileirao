# Tabela Brasileirao

Projeto de análise do Campeonato Brasileiro desenvolvido no Power BI, com dados obtidos por web scraping e atualizados conforme os jogos acontecem.

## Arquivos

- `Tabela Brasileirao.pbix`: relatório e modelo de dados do projeto.

## Como usar

1. Abra o arquivo `Tabela Brasileirao.pbix` no Power BI Desktop.
2. Atualize os dados para obter os resultados mais recentes dos jogos.
3. Explore as páginas e filtros para acompanhar a classificação do Brasileirão.

## Requisitos

- Power BI Desktop para Windows.
